# Color Theory and Palette Creation for Agents

Use [color-system-design](../skills/color-system-design/SKILL.md) when creating a brand palette, recoloring a Flutter/web UI, deriving semantic tokens, generating dark/light themes, extracting screenshot colors, or reviewing chart/heatmap accessibility.

Tools catalog: [color-tools.md](../skills/color-system-design/references/color-tools.md).

## Agent invocation
> Use color-system-design to inspect existing brand tokens, research three compatible palettes, calculate foreground/background contrast, recommend semantic light/dark UI tokens, and implement the selected palette. Verify in actual screens and keep the source design language.

## Integration
- Use [design-reference-research](../skills/design-reference-research/SKILL.md) for visual references.
- Use [frontend-ui-engineering](../skills/frontend-ui-engineering/SKILL.md) for implementation.
- Use Flutter MCP/Widgetbook or Playwright for visual verification.
- MCP servers must be configured in the coding client separately; this repo supplies skills and documentation only.
